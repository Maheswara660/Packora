# Internationalization

Packora uses an English-first user interface designed with clear, concise, and technical terminology across all Studio screens and generated WebAPKs.

## System Strings Architecture

1. **Android Resource Strings**:
   - Stored in `app/src/main/res/values/strings.xml` for app identity, notification channels, and system integration.
   - Example:
     ```xml
     <resources>
         <string name="app_name">Packora</string>
     </resources>
     ```

2. **Jetpack Compose UI**:
   - Modern Compose components in `app/src/main/java/com/maheswara660/packora/ui/` use semantic, well-defined English strings for clear labeling of security options, networking toggles, and build logs.

3. **Documentation Site**:
   - The official documentation site is strictly maintained in English for unified global collaboration and clarity.
