# Template & Shell Architecture

Standalone applications generated by Packora run on top of the **`:template`** module. Understanding how the template is compiled, staged, and loaded ensures that newly added features work seamlessly in both the Studio builder and exported APKs.

## The Template Module (`:template`)

The runtime template lives in the root directory under `template/`. It is a complete, minimal Android application module engineered for speed, low memory usage, and zero bloat:

- **Namespace**: `com.maheswara660.packora.template`
- **Main Activity**: `template/src/main/java/com/maheswara660/packora/template/MainActivity.kt`
- **Layout**: `template/src/main/res/layout/activity_main.xml`

## Automated Template Staging

Packora automates template synchronization directly in `app/build.gradle.kts` using a dedicated Gradle task:

```kotlin
val copyTemplateApk by tasks.registering(Copy::class) {
    description = "Copies the built template APK into app assets"
    group = "build"
    dependsOn(":template:assembleRelease")
    from(layout.projectDirectory.dir("../template/build/outputs/apk/release/template-release-unsigned.apk"))
    into(layout.projectDirectory.dir("src/main/assets/template"))
    rename { "webview_shell.apk" }
}
```

Whenever `:app` compiles, it automatically ensures that `:template:assembleRelease` is up-to-date and copies the resulting APK into:

```text
app/src/main/assets/template/webview_shell.apk
```

## Runtime Initialization Flow

When a user launches an exported standalone WebAPK:

1. **Activity Launch**: Android invokes `MainActivity.onCreate()` in `:template`.
2. **Asset Loading**: `MainActivity` opens `assets/app_config.json` via Android `AssetManager`.
3. **Configuration Parsing**:
   ```kotlin
   val inputStream = assets.open("app_config.json")
   val reader = InputStreamReader(inputStream)
   val text = reader.readText()
   reader.close()
   config = JSONObject(text)
   ```
4. **WebView Initialization**:
   - Applies hardware acceleration and DOM storage.
   - Sets Desktop Mode User-Agent if `isDesktopMode` is enabled.
   - Configures zoom controls, copy/paste policy, and text selection.
   - Binds JavaScript interfaces, Credential Manager, and download handlers.
5. **Security & Privacy Layer**:
   - Injects anti-fingerprinting canvas/WebGL scripts if configured.
   - Attaches strict DoH (DNS-over-HTTPS) resolver hooks.
6. **Navigation**: `webView.loadUrl(targetUrl)` displays the web application.

## Building the Template Manually

To rebuild the template APK independently:

```bash
./gradlew :template:assembleRelease :app:copyTemplateApk
```

To verify both modules compile cleanly together:

```bash
./gradlew :app:compileDebugKotlin :template:compileReleaseKotlin
```
